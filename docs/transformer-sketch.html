A transformer in Neurolume

How a small GPT-style model could look in the viewer, reading the sentence "the cat sat because it was tired". Three levels, opened the same way as today: the overview, one block, one attention head.

Level 1Overview

Each word is a token and gets its own lane, so the sentence flows through as 7 parallel bundles instead of one signal. The embedding turns each token into a vector. Every block card previews its attention pattern (top) and its per-token MLP (bottom). At the end, only the last token's lane goes on to predict the next word.

Level 2Inside block 3

Attention is the only place tokens mix: its stack of 8 squares is the 8 heads, like a conv's slabs, and the front one shows who looks at whom. The feed-forward part works on each token on its own, so the lanes widen (512 → 2048) and narrow again without crossing. Both parts have a skip connection into an add, drawn as arcs exactly like a ResNet block.

Level 3Head 3 of block 3

Clicking a head opens its attention matrix for the real input: each row is a token looking at the others, each column a token being looked at, and every row adds up to 1. This head has learned to link pronouns back to nouns: "it" puts 0.71 of its attention on "cat". The grey triangle is masked: a GPT-style model can only look at earlier words.
